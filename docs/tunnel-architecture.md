# معماری تانل ایران ↔ آلمان

## مسیرها (جدا از CDN)

```text
┌─────────────────────────────────────────────────────────────────┐
│  کاربران فعلی SS (۴۲+ کلاینت)                                    │
│  ایران :1080 → HAProxy → Rathole :19454 → آلمان :8388 (SS)      │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  VLESS داخل ایران (جدید / تست)                                  │
│  ایران :2088 یا :444 → Rathole → آلمان 127.0.0.1:18443 (VLESS)  │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  CDN (جدا — Cloudflare)                                         │
│  de.avashop.online:443 → Nginx → Docker Xray gRPC               │
└─────────────────────────────────────────────────────────────────┘
```

## سرورها

| سرور | IP | نقش |
|------|-----|-----|
| ایران | `80.249.112.56` | ورودی کاربران + Rathole Server `:3083` |
| آلمان | `49.13.6.108` | خروجی اینترنت + Rathole Client + CDN Origin |

## Rathole سرویس‌ها

| سرویس | ایران | آلمان |
|--------|-------|-------|
| `germany_ss_tcp/udp` | `127.0.0.1:19454` | `127.0.0.1:8388` |
| `germany_vless_iran` | `0.0.0.0:2088` | `127.0.0.1:18443` |
| `bot_sub_http` | `127.0.0.1:18080` | `127.0.0.1:8080` |

## مشکل رایج: قطع کاربران

**علت:** `systemctl restart rathole` روی ایران در حالی که یک پروسه orphan روی `:3083` در حال اجراست.

- systemd **۳۳۸ بار** ری‌استارت کرده و هر بار اتصال آلمان را `early eof` کرده
- **راه‌حل:** `rathole.service` را disable کنید، از `rathole-guard.service` استفاده کنید
- **هرگز** `systemctl restart rathole` نزنید مگر در پنجره نگهداری
