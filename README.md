# AVA CDN

A content delivery network (CDN) for fast, reliable distribution of static and dynamic assets.

## Overview

AVA CDN is designed to cache and serve content from edge locations close to end users, reducing latency and origin load.

## Features

- Global edge caching
- Configurable cache policies
- Origin shielding and failover support
